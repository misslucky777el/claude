# ЧИСТО.СТРОЙ — Gutenberg landing block

WordPress-плагин с одним кастомным **динамическим блоком** `chisto-stroy/landing`,
который воспроизводит лендинг клининговой компании (hero, услуги, «почему мы»,
этапы, цены, портфолио «до/после», отзывы, FAQ и форму заявки).

Собран с помощью навыка **gutenberg-block-authoring** (см. корень репозитория):
`block.json` → `edit.js`/`render.php` → сборка `@wordpress/scripts`.

## Что редактируется в редакторе

Блок вставляется как единое целое (категория «Тема» → «ЧИСТО.СТРОЙ — Лендинг»).
В правом сайдбаре редактируются:

- телефон (отображение и `tel:`-ссылка), e-mail, часы работы, регион;
- заголовок и подзаголовок hero;
- цена «от ₽/м²» (подставляется в hero и тариф «Грубая уборка»).

Остальной контент задаётся в `src/landing/render.php` (легко поправить).

## Установка и сборка

```bash
cd chisto-stroy-blocks
npm install
npm run build        # или npm start для режима наблюдения
```

Затем поместите папку `chisto-stroy-blocks/` в `wp-content/plugins/` и активируйте
плагин. На странице/записи добавьте блок **«ЧИСТО.СТРОЙ — Лендинг»**.

> Блок — динамический: разметка рендерится на сервере из `render.php`, поэтому в
> контенте записи хранится только `<!-- wp:chisto-stroy/landing … /-->`. Менять
> вёрстку можно без ошибок валидации блока.

## Структура

```
chisto-stroy-blocks.php      Бутстрап плагина (register_block_type из build/)
package.json                 Скрипты сборки @wordpress/scripts
src/landing/
  block.json                 Метаданные, атрибуты, supports, viewScript
  index.js                   Регистрация блока
  edit.js                    Превью (ServerSideRender) + контролы сайдбара
  save.js                    return null (динамический блок)
  render.php                 Серверный рендер всего лендинга
  view.js                    Фронт: бургер-меню, слайдер «до/после», reveal, форма
  style.scss                 Стили лендинга (фронт + редактор)
  editor.scss                Правки только для редактора
```

## Заметки

- Шрифты Manrope/Unbounded подключаются через `@import` в `style.scss`.
- Форма заявки показывает успешное состояние без отправки. Подключите реальный
  обработчик (admin-ajax / REST / CRM) в `view.js` — место помечено `TODO`.
- Стили `styles.css`/`main.js` исходного макета в задачу не входили, поэтому
  оформление и интерактив воссозданы заново под тот же фирменный стиль.
