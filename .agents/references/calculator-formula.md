# Формулы калькулятора (a — вид, b — площадь, c — клинеры)

Цена ступенчатая, **шаг диапазона 10 м²** (20–120). Внутри диапазона цена фиксированная.
`b > 120` → «рассчитать индивидуально». Референс кода — `landings/calc.js`.

## Номер диапазона n (по площади b)
```
n = МАКС(0; ОКРУГЛВВЕРХ((b − 20) / 10))
```
`b≤20`→0 · `20<b≤30`→1 · … · `110<b≤120`→10 · `b>120`→по запросу.

## Формулы цены (a, c)

| a — вид | c = 1 клинер | c = 2 клинера |
|---|---|---|
| **Поддерживающая** | `4500 + 250·n` | `7200 + 400·n`  (×1,6) |
| **Генеральная** | `10000 + 1000·n` | `15000 + 1500·n`  (×1,5) |
| **После ремонта** | `14000 + 1000·n` | `19000 + 1500·n`  (= генеральная + 4 000) |

Единая запись через «работы» `W = 10000 + 1000·n`:
- Генеральная: c1 = `W`,  c2 = `W × 1,5`
- После ремонта: c1 = `W + 4000`,  c2 = `W × 1,5 + 4000`  (доставка оборудования 4 000 ₽)
- Поддерживающая: c1 = `4500 + 250·n`,  c2 = `× 1,6`

Итог: `ИТОГО = ЦЕНА(a,b,c) + ОКНА + ВЫЕЗД_ЗА_МКАД`.

## Проверка (совпадает с прайсом)

| n | Площадь | Поддерж 1/2 | Генер 1/2 | Послестрой 1/2 |
|---|---|---|---|---|
| 0 | до 20 | 4 500 / 7 200 | 10 000 / 15 000 | 14 000 / 19 000 |
| 1 | 20–30 | 4 750 / 7 600 | 11 000 / 16 500 | 15 000 / 20 500 |
| 3 | 40–50 | 5 250 / 8 400 | 13 000 / 19 500 | 17 000 / 23 500 |
| 5 | 60–70 | 5 750 / 9 200 | 15 000 / 22 500 | 19 000 / 26 500 |
| 10 | 110–120 | 7 000 / 11 200 | 20 000 / 30 000 | 24 000 / 34 000 |

## Мойка окон (доп)
```
ОКНА = число_створок × ставка       ставка = 500 ₽ (обычная) / 1 000 ₽ (после ремонта)
```

## Выезд за МКАД
| Расстояние | Доплата |
|---|--:|
| в пределах МКАД / до 5 км | 0 ₽ |
| 5–10 км | 2 000 ₽ |
| 10–20 км | 4 000 ₽ |
| 20–30 км | 6 000 ₽ |
| 30–40 км | 8 000 ₽ |

## Пример
Генеральная, 50 м², 2 клинера, + 8 створок окон, 15 км за МКАД:
```
n = ОКРУГЛВВЕРХ((50−20)/10) = 3
W = 10000 + 1000×3 = 13000
ЦЕНА = W × 1,5 = 19 500
+ ОКНА 8 × 500 = +4 000
+ ВЫЕЗД (10–20 км) = +4 000
ИТОГО = 27 500 ₽
```

## Excel / Google Sheets
```
n     = МАКС(0; ОКРУГЛВВЕРХ((b-20)/10))
Поддерж   1кл = 4500 + 250*n     2кл = 7200 + 400*n
Генеральная 1кл = 10000 + 1000*n  2кл = 15000 + 1500*n
Послестрой 1кл = 14000 + 1000*n   2кл = 19000 + 1500*n
```
Выбор нужной строки по a и c — через ЕСЛИ() или три отдельных калькулятора.

## Как в Tilda
- 3 калькулятора (по услуге) или один с переключателем «Тип уборки».
- Поле «Площадь» — слайдер/число; в формуле блока задать `n` и цену как выше.
- «Клинеры» (1/2) — выбирает 1кл/2кл-формулу.
- Опц. «Створки окон» (+N·500 / ·1000) и «Выезд за МКАД» (по зонам).
- Либо блок «HTML» с готовым `landings/calc.js` (точные значения).
- Свыше 120 м² / 40 км — «рассчитать индивидуально» + заявка.
