# CSV для загрузки в Яндекс Директ — Генеральная уборка

Кампания: **Генеральная уборка** · бренд **ГенералКлининг** · Москва и МО · от 10 000 ₽
Источник текстов и группировки: `../yandex-direct-generalnaya.md`

## Файлы

| Файл | Что внутри |
|---|---|
| `ads.csv` | 23 объявления по 13 группам (G1–G13): 2 заголовка, текст, ссылка с UTM, отображаемая ссылка, уточнения, быстрые ссылки. |
| `keywords.csv` | Ключевые фразы по тем же группам (одна фраза на строку). |
| `minus-words.txt` | Минус-слова на всю кампанию (DIY/инфо/гео-мусор/работа). |

Все CSV — в кодировке **UTF-8 с BOM**, чтобы кириллица корректно открывалась
в Excel и Директ Коммандере.

## Как загрузить

Два рабочих пути:

### Вариант 1 — Директ Коммандер (рекомендую)
1. Создать кампанию «Генеральная уборка» в Коммандере (или в веб-интерфейсе и
   синхронизировать).
2. Группы объявлений завести по столбцу `Группа` (G1–G13). Имя группы = посадочная
   страница + интент.
3. Перенести данные из `ads.csv` в карточки объявлений: Заголовок 1 / Заголовок 2 /
   Текст / Ссылка. Уточнения и быстрые ссылки — поля разделены символом `|`.
4. Ключевые фразы из `keywords.csv` разложить по группам (фильтр по столбцу `Группа`).
5. Минус-слова из `minus-words.txt` добавить на уровень кампании
   (Параметры → Минус-фразы).
6. **Кросс-минусация** между группами: комнатность (G5/G6/G7), офис (G8), дом (G9),
   окна (G10), кухня/санузел (G11), после ремонта (G12) развести, чтобы фразы не
   перехватывались соседними группами. В Коммандере — «Корректировка пересечений».

### Вариант 2 — веб-интерфейс, импорт из XLS/CSV
Шаблон Директа для импорта содержит больше столбцов (Доп. объявление, регион показа,
ставки и т. п.). Эти файлы покрывают только смысловые поля. Удобнее открыть
официальный шаблон Директа, вставить колонки из `ads.csv` в соответствующие поля и
догрузить недостающее (регион — Москва и область; ставки — на ваше усмотрение).

## ⚠️ Перед загрузкой проверить

1. **URL посадочных.** В ссылках используются заглушки слугов:
   - `general-cleaning.ru/ceny` — страница цен;
   - `general-cleaning.ru/general` — генеральная уборка;
   - `general-cleaning.ru/biznes` — для бизнеса/офис;
   - `general-cleaning.ru/remont` — после ремонта.

   Заменить на реальные адреса страниц Tilda (у Tilda обычно вида
   `general-cleaning.ru/uborka`, `/ceny`, `tilda.ws/...` или ЧПУ). UTM-метки оставить.
2. **Лимиты Директа** соблюдены: Заголовок 1 ≤ 56, Заголовок 2 ≤ 30, Текст ≤ 81.
   Длины проверены в `../yandex-direct-generalnaya.md`.
3. **Телефон/контакты** в визитке кампании — задать в интерфейсе (в CSV их нет).
4. **Регион показа** — Москва и область — выставить на кампании.
