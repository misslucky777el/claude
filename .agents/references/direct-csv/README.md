## Логика группировки (тесные группы под жирный)

Каждая группа — **один смысл**, и Заголовок 1 содержит саму маску запроса.
Тогда Яндекс подсвечивает совпадение **жирным** → выше CTR и качество, ниже цена клика.
Объекты (кухня, окна, ванная, дом) и комнатность забирают свои «цена/стоимость/сколько стоит».

**3 отдельные кампании** (столбец «Кампания»):

## Как загрузить (Директ Коммандер, рекомендую)

1. Создать **3 кампании** по столбцу «Кампания»: «Генеральная B2C», «После ремонта», «B2B — коммерция».
2. В каждой завести **группы** по столбцу «Группа». Одна группа = одна маска.
3. Данные объявлений — из `ads.csv`: Заголовок 1 / Заголовок 2 / Текст / Ссылка.
   Уточнения и быстрые ссылки разделены символом `|`.
4. Ключи — из `keywords.csv` (фильтр по «Группа»), раскладываем по группам.
5. Минус-слова — из `minus-words.txt` на уровень аккаунта/кампании.
6. **Кросс-минусация** обязательна: развести пересечения между объектными и
   комнатными группами (Коммандер → «Корректировка пересечений»), чтобы фраза
   показывалась именно в своей группе (и подсвечивался нужный заголовок).

> Веб-импорт: официальный шаблон Директа содержит больше столбцов (регион, ставки,
> доп. объявление). Эти файлы покрывают смысловые поля — остальное дозаполнить в шаблоне.

## ⚠️ Перед загрузкой проверить

1. **URL посадочных** — заглушки слугов, заменить на реальные адреса Tilda (UTM оставить):
   - `/general` — генеральная (Квартира, Москва, Дом, Кухня, Ванная, Клининг, Ген. клининг, Услуги);
   - `/moyka-okon` — мойка окон (группа Окна);
   - `/ceny` — Цена, Стоимость, Сколько стоит, Что входит;
   - `/generalnaya-1-komnatnaya`, `/-2-`, `/-3-` — комнатные (свёрстаны в `landings/`);
   - `/remont` — После ремонта;
   - `/biznes` — Офис, Помещения/коммерция.
   Соответствие слуг → готовым страницам в `landings/`:
   `/general`→`general-uborka.html` · `/ceny`→`ceny.html` ·
   `/generalnaya-{1,2,3}-komnatnaya`→одноимённые · `/moyka-okon`→`moyka-okon.html` ·
   `/remont`→`posle-remonta.html` · `/biznes`→`dlya-biznesa.html`.
2. **Лимиты Директа** соблюдены (проверено скриптом): Заголовок 1 ≤ 56, Заголовок 2 ≤ 30, Текст ≤ 81, уточнение ≤ 25.
3. **Телефон/визитка/регион** (Москва и область) — задать в интерфейсе кампании.
4. **Ставки** — B2B обычно дороже; вести отдельной кампанией удобно для бюджета.
