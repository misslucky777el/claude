# Яндекс Аудитории, look-alike и ретаргетинг (КлинГрупп)

*Последнее обновление: 2026-06-22*

> Легальные способы работы с тёплой и похожей аудиторией в Яндекс Директе для КлинГрупп
> (Москва и МО). Контекст — `.agents/product-marketing.md`.
> ⚠️ Лимиты Аудиторий и правила по брендам в Директе меняются — проверяйте актуальное
> в справке Яндекса перед запуском.

## 1. Яндекс Аудитории из своей базы (CRM)
**Нужно:** телефоны/email клиентов и заявок, минимум ~1000 контактов (можно хэшированными).

**Шаги:**
1. audience.yandex.ru → «Создать сегмент» → данные из CRM → загрузить CSV.
2. Подтвердить законное основание (это ваши клиенты с согласием).
3. Дождаться матчинга.
4. В Директе: условия показа → «Ретаргетинг и подбор аудитории» → выбрать сегмент.

**Сценарии:**
- Исключать действующих клиентов из кампаний на привлечение.
- Допродажи: заказывал генеральную → предложить подписку на регулярную −20%.
- Реактивация: не заказывал 3–6 мес → оффер с промокодом.

## 2. Look-alike (похожие)
1. На базе сегмента «лучшие клиенты по LTV» (постоянные + B2B) → «Создать похожий сегмент».
2. Ползунок точность ↔ охват — старт ближе к точности.
3. Использовать в РСЯ для расширения.
> LAL строить на узком качественном сегменте, не на «всех подряд».

## 3. Ретаргет по посетителям своих лендингов
1. Метрика на всех лендингах + цели: «был на услуге, не оставил заявку», «начал заявку», «посетил B2B-страницу».
2. Сегменты в Метрике/Аудиториях по целям и страницам.
3. Кампании ретаргета в РСЯ по этапам:

| Сегмент | Окно | Сообщение |
|---|---|---|
| Был на услуге, не оставил заявку | 1–7 дней | «Слоты на сегодня/завтра» + −15% |
| Любой визит | 7–30 дней | соцдоказательство, отзывы |
| B2B-страница | 30 дней | «Расчёт за м² / обсудить» |

4. Исключения: оставившие заявку (7–14 дней) и действующие клиенты.

## 4. «Ретаргет по посетителям конкурентов» — важно
**Прямого ретаргета по посетителям чужих сайтов не существует** ни в одной легальной системе:
ретаргет работает только через пиксель/счётчик на сайте, а на сайт конкурента его не поставить.
Кто обещает «посетителей сайта конкурента» — это серый парсинг или подмена понятий.

**Легальный аналог — conquesting (перехват спроса):**
- Поиск по брендам конкурентов: ключи `qlean`, `клинон отзывы`, `домовёнок цены`,
  `[конкурент] альтернатива`. Показываем своё объявление с выгодой.
- РСЯ по тем же ключам — поведенческий таргет на интересовавшихся брендами конкурентов.
- DMP-сегменты «интересуются клинингом» (арендуемые) — это интерес к категории, не конкретный конкурент.

**⚠️ Правовой нюанс:**
- Товарный знак конкурента **нельзя в тексте/заголовке** объявления (нарушение, снимут по жалобе).
- В ключевых словах бренд использовать можно, но конкурент может заблокировать через жалобу.
- Стабильнее делать ставку на горячие небрендовые ключи («уборка после ремонта цена»,
  «генеральная уборка срочно»), бренды — аккуратно и точечно.

## Чек-лист запуска
- [ ] Метрика + цели на лендингах (без этого нет ретаргета).
- [ ] Выгрузить базу клиентов (с согласием) → сегмент в Аудиториях → look-alike на лучших.
- [ ] Кампании ретаргета в РСЯ по этапам + исключения.
- [ ] Conquesting: отдельная поисковая кампания по брендам конкурентов (бренды — только в ключах).
