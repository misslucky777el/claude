# Telegram-бот @KlinGroupBot — сценарий (КлинГрупп)

*Последнее обновление: 2026-06-22*

> Бот приёма заявок для клинингового сервиса КлинГрупп (Москва и МО).
> Цель: довести до заявки (имя + телефон + услуга + площадь), выдать промокод −15%,
> зафиксировать источник из deep-link. Контекст — `.agents/product-marketing.md`.
> Заменить @KlinGroupBot, телефон и ссылки на реальные. `[Кнопка]` = inline-кнопка.

## Атрибуция источника
Ссылки вида `t.me/KlinGroupBot?start=<source>` — параметр `<source>` сохраняется в заявке:
- `tgads_general` / `tgads_remont` / `tgads_reg` / `tgads_b2b` — Telegram Ads по услуге
- `seed_<channel>` — посев в конкретном канале
- `site_<page>` — переход с лендинга
Если `start` пустой — источник «direct».

## Служебное
- `[⬅️ Назад]` — на предыдущий экран; `[🏠 В начало]` — на Экран 0.
- `/help` → краткая подсказка + кнопка `[💰 Рассчитать]`.
- Нераспознанный ввод вне сценария: «Не совсем понял 🙂 Нажмите кнопку ниже» + меню.
- Если пользователь бросил заявку на шаге телефона — через 1–2 часа авто-напоминание:
  «Не закончили заявку? Оставьте номер — посчитаем и дадим −15% на первый заказ 🎁».
- Все тексты — на «вы», дружелюбно, без давления; для сегмента «запущенный случай» — без осуждения.
