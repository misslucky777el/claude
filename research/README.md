# Маркетинговые материалы: агентство по новостройкам Москвы

Актуальная версия на 31 августа 2026 года. В этой папке лежат **только действующие документы** —
устаревшие версии не хранятся отдельными файлами, их полный текст доступен в истории коммитов.

Каждый документ существует в двух форматах: `.md` для чтения и правки, `.html` — та же версия,
опубликованная как страница.

## История пересмотра

1. Первая версия УТП («План вместо мечты») строилась на широте выбора, скорости подборки, сравнении
   по параметрам и бесплатности для клиента.
2. Конкурентный анализ показал, что бесплатный подбор и сопровождение с 2025 года дают ЦИАН и
   Домклик, а подборку из 5–7 объектов в мессенджер — Самолёт Плюс.
3. Затем выяснилось, что **все агенты рынка работают через один профессиональный сервис
   (TrendAgent)**: база с 37 фильтрами, интерактивное сравнение и презентация клиенту,
   аэропанорамы стройки, расчёт ипотеки с заявкой в банк, бронирование в два клика.
   Это обнулило весь продуктовый слой позиционирования.
4. Ядро перенесено туда, где сервис бессилен: глубинное интервью, выезд и проверка конкретного лота
   на месте, прямой ответ «брать или не брать». Первая версия УТП удалена из папки, всё живое из неё
   перенесено в раздел 5б действующего документа.

**Важная оговорка, которую легко потерять:** доступа в профессиональный сервис у прямых покупателей
нет. Поэтому широта выбора остаётся рабочим аргументом против прямого визита к застройщику
(«зачем вообще агент») и никогда — против другого агента («почему вы»).
